# Windows

Projet Electron/electron-builder avec cible NSIS. Dans la distribution source complète, récupérer les cœurs EmulatorJS puis exécuter `npm install` et `npm run dist` depuis `windows/`. La CI Windows doit produire un installeur `.exe` et le publier sur la Release du tag. Aucun exécutable n’est inclus dans le dépôt à ce stade.
