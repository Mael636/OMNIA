# OMNIA sur iPhone

Version web autonome installable sur l’écran d’accueil de l’iPhone. Les jeux importés et les états restent dans le stockage local du navigateur.

## Installation

1. Hébergez ce dossier en HTTPS ou ouvrez-le via un serveur web local dans Documents.
2. Ouvrez `OMNIA.html` dans Safari.
3. Touchez **Partager → Sur l’écran d’accueil**.
4. Importez uniquement des jeux que vous possédez.

> Le navigateur ne peut pas lancer les cœurs WebAssembly depuis `file://`. Les jeux, BIOS et données de jeu ne sont pas inclus. Les cœurs locaux sont distribués sous `vendor/emulator/data/`.
