# OMNIA sur iPhone

Le dossier iPhone complet est dans la distribution OMNIA. Servir OMNIA.html en HTTP(S), ouvrir l’adresse avec Safari, puis choisir Partager → Ajouter à l’écran d’accueil. `file://` n’autorise pas le lancement des cœurs WASM. Aucun BIOS ni jeu n’est inclus. Les cœurs EmulatorJS doivent être récupérés depuis la distribution source complète.
